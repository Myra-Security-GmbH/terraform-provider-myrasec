# myrasec_ssl_provider_credentials

Use this data source to look up SSL provider credentials (Sectigo or D-Trust accounts used for Myra Managed Certificates).

## Example usage

```hcl
# Look for the Sectigo credentials
data "myrasec_ssl_provider_credentials" "sectigo" {
  filter {
    certificate_provider = "SECTIGO"
  }
}
```

## Argument Reference

The following arguments are supported:

* `filter` Filter the SSL provider credentials.

### filter
* `certificate_provider` (Optional) Restrict the result to one provider: `SECTIGO` or `DTRUST`.
* `search` (Optional) Restrict the result to credentials whose name, email or EAB key identifier contains the search string.

## Attributes Reference
* `credentials` A list of SSL provider credentials.

### credentials
* `id` The ID of the credentials.
* `created` Date of creation.
* `modified` Date of last modification.
* `name` User-defined label for the credentials.
* `certificate_provider` The certificate provider: `SECTIGO` or `DTRUST`.
* `cert` Public certificate of the ACME account key pair. Empty when the key pair was generated by the server.
* `email` Contact email address of the provider account.
* `endpoint` ACME directory URL of the provider product.
* `eab_kid` External Account Binding (EAB) key identifier.
* `comment` Free-text note.

**Note:** The `eab_hmac` and the `private_key` are never returned by the API and are not part of this data source.
